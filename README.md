# Raíz Terapia — Psicología Clínica

Landing page premium para consultorio de psicología. Desarrollada con React + Vite + Tailwind CSS.

## Stack

- **React** (functional components + hooks)
- **Vite** — bundler y dev server
- **Tailwind CSS v4** — estilos y diseño
- **Google Fonts** — Cormorant Garamond + DM Sans

## Funcionalidades

- Agenda inteligente en 4 pasos (sin base de datos, integración WhatsApp)
- Sección "Sobre mí" con bio y credenciales
- Especialidades con hover interactivo
- Carrusel de testimonios drag-to-scroll
- FAQ accordion animado
- Cursor personalizado
- Animaciones de scroll reveal
- WhatsApp floating button
- Diseño mobile-first responsive

## Instalación

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
